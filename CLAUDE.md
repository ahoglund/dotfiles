# Dotfiles — Claude Context

Personal dotfiles for Drew. Targets **macOS** and **Linux (Arch/Omarchy)**.

## Structure

GNU Stow layout — each top-level directory is a stow package. Running `stow <pkg>` from the repo root symlinks its contents into `$HOME`.

```
alacritty/   → ~/.config/alacritty/
bin/         → ~/bin/
git/         → ~/.gitignore_global, ~/.git_template/
gpg/         → ~/.gnupg/
hammerspoon/ → ~/.hammerspoon/          (macOS only)
misc/        → ~/.config/starship.toml, ~/.config/yamllint/, ~/.ctags, ~/.clipper.json
nvim/        → ~/.config/nvim/lua/config/ + lua/plugins/personal.lua
ruby/        → ~/.gemrc, ~/.irbrc
zellij/      → ~/.config/zellij/
zsh/         → ~/.zshrc, ~/.zprofile
```

Non-stow files at repo root: `Brewfile`, `packages.arch`, `.mise.toml`, `install.sh`, `setup.sh`, `reset.sh`, `gitconfig.example`.

## Key Design Decisions

**Shell:** Zsh + Oh-My-Zsh. Plugins: `zsh-autosuggestions`, `zsh-syntax-highlighting`, `zsh-history-substring-search`, `fzf`, `z`, `git`. Prompt: Starship (`misc/.config/starship.toml`).

**Package management:**
- macOS: Homebrew (`Brewfile`)
- Linux: pacman (`packages.arch`) — no Homebrew on Linux
- Language versions: `mise` on both platforms (replaces nodenv + rbenv). Global defaults in `.mise.toml` at repo root; per-project overrides go in a `.mise.toml` in that repo.

**Multiplexer:** Zellij (replaced tmux). Config at `zellij/.config/zellij/config.kdl`.

**Editor:** Neovim via Omarchy's LazyVim install (`~/.config/nvim/`). Omarchy owns the base config — dotfiles only symlink a personal overlay layer:
- `nvim/.config/nvim/lua/config/options.lua` — vim options
- `nvim/.config/nvim/lua/config/keymaps.lua` — keymaps (vim-test under `<leader>t`)
- `nvim/.config/nvim/lua/config/autocmds.lua` — strip whitespace, tabs→spaces
- `nvim/.config/nvim/lua/plugins/personal.lua` — personal plugins (copilot, vim-test, vim-rails, etc.)

**vim-test strategy:** custom `zellij` strategy — runs tests in a zellij floating pane when inside a zellij session (`$ZELLIJ` env var present), falls back to a nvim terminal split otherwise.

**Gitconfig:** `gitconfig.example` is a template; `~/.gitconfig` is generated by `setup.sh` (credential helper differs by OS, SSH URL remapping for non-Codespaces). Never commit the generated `gitconfig`.

**Private/OS config:** `~/.zsh_private` (secrets, tokens) and `~/.zsh_os` (machine-specific) are touched by `setup.sh` and gitignored.

## Install / Setup

```bash
./install.sh   # fresh machine — installs deps, OMZ, mise, links dotfiles
./setup.sh     # already bootstrapped — just re-links stow packages
```

`setup.sh` is idempotent (`stow --restow`). Safe to re-run.

## Omarchy Stub Files

Omarchy pre-creates certain plain files that our stow packages need to replace with symlinks. `setup.sh` explicitly `rm -f`s these before stowing. If a new stow package conflicts with an existing plain file, add a `rm -f` for it in `setup.sh` before the relevant `stow_pkg` call. Currently handled: `~/.config/nvim/lua/config/{options,keymaps,autocmds}.lua` and `~/.config/starship.toml`.

## Adding a New Config

1. Create a stow package directory: `mkdir -p newpkg/.config/newpkg/`
2. Put config files inside it
3. Add `stow_pkg newpkg` to `setup.sh`
4. Add the package to `Brewfile` (macOS) and/or `packages.arch` (Linux)

## OS Notes

- `hammerspoon` stow package is macOS-only (guarded in `setup.sh`)
- GNU sed path (`/opt/homebrew/opt/gnu-sed/libexec/gnubin`) is macOS-only, guarded in `.zshrc`
- Homebrew is macOS only — do not add it to the Linux path
- Omarchy (Linux) handles window management via Hyprland — no equivalent of Hammerspoon needed
